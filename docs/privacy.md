# 隐私与加密边界

## 能保护什么

VLESS + REALITY 使用 TLS 1.3 承载流量：

- 本地运营商看不到隧道内的目标 IP、域名、DNS、HTTP 内容；
- 未认证探测会得到伪装网站的真实证书；
- 主动探测更难识别出代理。

## 不能保护什么

- 服务器仍然知道你访问的目标 IP/域名（TLS SNI、DNS、流量元数据）；
- 服务器看不到 HTTPS 的正文内容，但能看到访问了哪些站点；
- YouTube/Google 仍然能看到服务器 IP、登录账号、浏览器指纹；
- 高级对手可以做流量关联分析；
- 没有“绝对匿名”或“永远不会被封锁”。

如果目标是隐藏访问目标本身，需要 Tor 或多跳代理，而不是单一 REALITY 节点。
